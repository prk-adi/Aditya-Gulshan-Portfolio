# Aditya Gulshan Portfolio

A responsive personal portfolio website for Aditya Gulshan, built with HTML, CSS, and JavaScript.

The site presents a fresher software engineering profile with a focused introduction, technical skills, education, certifications, featured projects, community involvement, resume download, and contact links.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- GitHub REST API for recent repository cards

## Main Sections

- Hero profile summary
- Experience
- Technical skills
- Certifications and job simulations
- Education
- Featured projects
- Recent GitHub projects
- Community and affiliations
- Languages
- Contact

## Featured Projects

- SmartBike ERP System
  - C++, HTML, CSS, JavaScript
  - Inventory, bookings, sales billing, reporting, and CSV export

- Secure Password Generator
  - HTML, CSS, JavaScript, Web Crypto API, Service Worker
  - Password generation, strength feedback, local vault features, import/export, and PWA support

- PRK Music Player
  - HTML, CSS, JavaScript, HTMLAudioElement, IndexedDB
  - Local music playback, playlists, queue tools, favorites, lyrics, and browser persistence

## Files

- `index.html` - main portfolio structure
- `styles.css` - visual design, layout, project previews, and responsive rules
- `script.js` - footer year, reveal animation, and GitHub project loading
- `Aditya_Gulshan_Resume.pdf` - downloadable resume
- `profile-photo-252.jpg` - optimized profile photo used on the page
- `favicon-64.png` - small browser tab icon
- `project-music-player-960.jpg` - optimized featured project screenshot

## How To Open

Open `index.html` in any modern browser. No installation or build step is required.

Some project demo buttons point to sibling folders in the local `E:\Dev` workspace. When deploying this portfolio online, replace those local demo links with hosted demo URLs.

## Customization

- Update personal text and section content in `index.html`
- Replace `Aditya_Gulshan_Resume.pdf` when the resume changes
- Replace or add project screenshots for featured project cards
- Update colors, spacing, and responsive behavior in `styles.css`
- Update the GitHub username or repository loading behavior in `script.js`
